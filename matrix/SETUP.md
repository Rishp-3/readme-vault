# Setup: /matrix

Green code rain

1. Create a public repo named exactly like your GitHub username (if you haven't).
2. Copy **everything inside this folder** (including the hidden `.github` folder, if present) into the root of that repo. This folder mirrors a profile repo, so nothing else is needed.
3. Replace the sample data with yours (search and replace in `README.md`): `Rishp-3` → your GitHub username, `Rishabh` / `RISHABH` → your name, `rp6229553@gmail.com` → your email, and the social links (LinkedIn `rishp3`, X and Instagram `rishp_3`, YouTube `@rishp3`, Medium `@rishp-3`). Edit the About, Learning and Tech Stack sections too.
4. Go to **Actions** and run **Generate Snake Animation** once. It creates the `output` branch used by the README. (Settings → Actions → General → Workflow permissions → Read and write.)
5. Create a WakaTime account, copy your API key and save it as repo secret `WAKATIME_API_KEY`. Then run **Waka Readme** from Actions.
6. Run **Update GitHub Trophies** from Actions to regenerate `trophy.svg` for your account (the included file is a sample).
7. Run **Activity Graph** from Actions to regenerate `activity-graph.svg` for your account (the included file is a sample).
8. Commit. Your profile is live. 🚀
