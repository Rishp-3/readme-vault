# Colors — 04 Hacker Terminal

| Hex | Role |
|---|---|
| `#050A05` | bg |
| `#33FF66` | text |
| `#1A8F3C` | dim |
| `#0F2A14` | bar |
| `#FFBD2E` | warn |

**Contrast:** text `#33FF66` on background `#050A05` = **14.86:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=050A05&title_color=33FF66&text_color=1A8F3C&icon_color=FFBD2E&border_color=0F2A14&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=050A05&title_color=33FF66&text_color=1A8F3C&icon_color=FFBD2E&border_color=0F2A14&hide_border=false
```
