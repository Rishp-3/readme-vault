# Colors — 05 Code Editor

| Hex | Role |
|---|---|
| `#1E1E1E` | bg |
| `#252526` | sidebar |
| `#2D2D2D` | tab |
| `#D4D4D4` | text |
| `#569CD6` | keyword |
| `#CE9178` | string |
| `#DCDCAA` | fn |
| `#6A9955` | comment |
| `#B5CEA8` | number |

**Contrast:** text `#D4D4D4` on background `#1E1E1E` = **11.25:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=1E1E1E&title_color=569CD6&text_color=D4D4D4&icon_color=DCDCAA&border_color=252526&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=1E1E1E&title_color=569CD6&text_color=D4D4D4&icon_color=DCDCAA&border_color=252526&hide_border=false
```
