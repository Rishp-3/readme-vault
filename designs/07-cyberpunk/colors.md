# Colors — 07 Cyberpunk

| Hex | Role |
|---|---|
| `#140A28` | bg1 |
| `#0A0A1F` | bg2 |
| `#FF2BD6` | pink |
| `#00E5FF` | cyan |
| `#F7E03C` | yellow |
| `#2A1450` | panel |

**Contrast:** text `#FFFFFF` on background `#140A28` = **19.03:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=0A0A1F&title_color=FF2BD6&text_color=E2E8F0&icon_color=00E5FF&border_color=2A1450&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=0A0A1F&title_color=FF2BD6&text_color=E2E8F0&icon_color=00E5FF&border_color=2A1450&hide_border=false
```
