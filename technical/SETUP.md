# Setup: /technical

Showcase your stack, tools and depth

1. Create a public repo named exactly like your GitHub username (if you haven't).
2. Copy **everything inside this folder** (including the hidden `.github` folder, if present) into the root of that repo. This folder mirrors a profile repo, so nothing else is needed.
3. Replace `YOUR_USERNAME` everywhere with your username, and fix the other placeholders (`YOUR_NAME`, `YOUR_ROLE`, `YOUR_TAGLINE`, `YOUR_PROJECT`, `YOUR_TECH`, `YOUR_TOPIC`, `YOUR_CITY`, links).
4. The workflow `.github/workflows/metrics.yml` is already in place, it just needs to be copied along with everything else.
5. Create a personal access token and save it as repo secret `METRICS_TOKEN`. Run the workflow; it writes `github-metrics.svg`.
6. Commit. Your profile is live. 🚀
