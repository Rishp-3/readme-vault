# Colors — 18 Forest Green

| Hex | Role |
|---|---|
| `#0F3D22` | bg |
| `#166534` | pine |
| `#22C55E` | green |
| `#86EFAC` | light |
| `#7C5A3A` | trunk |
| `#DCFCE7` | text |

**Contrast:** text `#DCFCE7` on background `#0F3D22` = **11.18:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

```

```
