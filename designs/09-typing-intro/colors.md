# Colors — 09 Typing Intro

| Hex | Role |
|---|---|
| `#0D1117` | bg |
| `#C9D1D9` | text |
| `#58A6FF` | accent |
| `#58A6FF` | caret |
| `#8B949E` | muted |

**Contrast:** text `#C9D1D9` on background `#0D1117` = **12.26:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=0D1117&title_color=58A6FF&text_color=C9D1D9&icon_color=8B949E&border_color=30363D&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=0D1117&title_color=58A6FF&text_color=C9D1D9&icon_color=8B949E&border_color=30363D&hide_border=false
```
