# Colors — 19 Glassmorphism

| Hex | Role |
|---|---|
| `#312E81` | bg1 |
| `#0EA5E9` | bg2 |
| `#F0ABFC` | blob1 |
| `#38BDF8` | blob2 |
| `#FFFFFF` | glass |
| `#FFFFFF` | border |
| `#FFFFFF` | text |

**Contrast:** text `#FFFFFF` on background `#312E81` = **11.42:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.
