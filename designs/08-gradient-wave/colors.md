# Colors — 08 Gradient Wave

| Hex | Role |
|---|---|
| `#0F172A` | bg |
| `#06B6D4` | g1 |
| `#8B5CF6` | g2 |
| `#E2E8F0` | text |

**Contrast:** text `#E2E8F0` on background `#0F172A` = **14.48:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.
