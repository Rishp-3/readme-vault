# Colors — 15 Neon Dark

| Hex | Role |
|---|---|
| `#0A0A0A` | bg |
| `#00F0FF` | cyan |
| `#39FF14` | green |
| `#FF2EC4` | magenta |
| `#F5F5F5` | text |

**Contrast:** text `#F5F5F5` on background `#0A0A0A` = **18.16:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=0A0A0A&title_color=00F0FF&text_color=F5F5F5&icon_color=FF2EC4&border_color=1A1A1A&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=0A0A0A&title_color=00F0FF&text_color=F5F5F5&icon_color=FF2EC4&border_color=1A1A1A&hide_border=false
```
