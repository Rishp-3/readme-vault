# Setup: /student

For beginners and learners

1. Create a public repo named exactly like your GitHub username (if you haven't).
2. Copy **everything inside this folder** (including the hidden `.github` folder, if present) into the root of that repo. This folder mirrors a profile repo, so nothing else is needed.
3. Replace the sample data with yours (search and replace in `README.md`): `Rishp-3` → your GitHub username, `Rishabh` / `RISHABH` → your name, `rp6229553@gmail.com` → your email, and the social links (LinkedIn `rishp3`, X and Instagram `rishp_3`, YouTube `@rishp3`, Medium `@rishp-3`). Edit the About, Learning and Tech Stack sections too.
4. Create a WakaTime account, copy your API key and save it as repo secret `WAKATIME_API_KEY`. Then run **Waka Readme** from Actions.
5. Run **Update GitHub Trophies** from Actions to regenerate `trophy.svg` for your account (the included file is a sample).
6. Commit. Your profile is live. 🚀
