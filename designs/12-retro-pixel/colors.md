# Colors — 12 Retro Pixel

| Hex | Role |
|---|---|
| `#2B2D42` | bg |
| `#FFD166` | yellow |
| `#EF476F` | red |
| `#06D6A0` | green |
| `#EDF2F4` | white |

**Contrast:** text `#EDF2F4` on background `#2B2D42` = **11.95:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=2B2D42&title_color=FFD166&text_color=EDF2F4&icon_color=EF476F&border_color=06D6A0&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=2B2D42&title_color=FFD166&text_color=EDF2F4&icon_color=EF476F&border_color=06D6A0&hide_border=false
```
