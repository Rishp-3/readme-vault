# Colors — 11 Glow Pulse

| Hex | Role |
|---|---|
| `#0B0B1A` | bg |
| `#A78BFA` | violet |
| `#F472B6` | pink |
| `#E9D5FF` | text |

**Contrast:** text `#E9D5FF` on background `#0B0B1A` = **14.32:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=0B0B1A&title_color=A78BFA&text_color=E9D5FF&icon_color=F472B6&border_color=2A1B4A&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=0B0B1A&title_color=A78BFA&text_color=E9D5FF&icon_color=F472B6&border_color=2A1B4A&hide_border=false
```
