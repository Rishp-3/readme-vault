# Colors — 06 Matrix Rain

| Hex | Role |
|---|---|
| `#000000` | bg |
| `#E8FFE8` | head |
| `#00FF41` | bright |
| `#008F23` | mid |
| `#003B10` | dim |

**Contrast:** text `#FFFFFF` on background `#000000` = **21.00:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.
