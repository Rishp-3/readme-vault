# Colors — 03 Monochrome

| Hex | Role |
|---|---|
| `#000000` | bg |
| `#FFFFFF` | text |
| `#8A8A8A` | dim |
| `#3A3A3A` | frame |
| `#111111` | black2 |

**Contrast:** text `#FFFFFF` on background `#000000` = **21.00:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=111111&title_color=FFFFFF&text_color=8A8A8A&icon_color=FFFFFF&border_color=3A3A3A&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=111111&title_color=FFFFFF&text_color=8A8A8A&icon_color=FFFFFF&border_color=3A3A3A&hide_border=false
```
