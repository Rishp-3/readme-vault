# Colors — 16 Space Galaxy

| Hex | Role |
|---|---|
| `#05051A` | bg |
| `#6366F1` | indigo |
| `#C084FC` | violet |
| `#F0ABFC` | pink |
| `#FFFFFF` | star |

**Contrast:** text `#FFFFFF` on background `#05051A` = **20.13:1** (passes WCAG AA 4.5:1 target).


**This design is dark-only.** No light variant is provided because the palette depends on a dark background for contrast and glow effects.

## Ready-to-paste stats-card parameters

```
bg_color=05051A&title_color=C084FC&text_color=E2E8F0&icon_color=6366F1&border_color=1A1A3A&hide_border=false
```
