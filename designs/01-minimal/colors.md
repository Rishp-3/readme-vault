# Colors — 01 Minimal

| Hex | Role |
|---|---|
| `#FFFFFF` | bg |
| `#0B0B0B` | bg_dark |
| `#111111` | text |
| `#F5F5F5` | text_dark |
| `#6B7280` | muted |
| `#E5E7EB` | line |
| `#111111` | accent |

**Contrast:** text `#111111` on background `#FFFFFF` = **18.88:1** (passes WCAG AA 4.5:1 target).

## Ready-to-paste stats-card parameters

```
bg_color=ffffff00&title_color=111111&text_color=6B7280&icon_color=111111&border_color=E5E7EB&hide_border=false
```

Paste after any `github-readme-stats` / `streak-stats` URL, e.g.

```
https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&bg_color=ffffff00&title_color=111111&text_color=6B7280&icon_color=111111&border_color=E5E7EB&hide_border=false
```
